Kenapa Kelly = 0

f* = (b·p − q) / b
b = 0.844  (payoff ratio)
p = 0.408  (win rate)
q = 0.592  (1 − p)

f* = (0.844×0.408 − 0.592) / 0.844
f* = −0.29  → clipped to 0

Expected value negatif secara historis pada bucket ini (forward return 20 hari rata-rata −3.1%). Sistem menolak menyarankan ukuran posisi apa pun, bukan membulatkan ke angka kecil yang terlihat aman.

Cara kerja

Semua kompute jalan di Snowflake

Dari export data mentah MESSE sampai jawaban agent, tidak ada logika bisnis yang lari di aplikasi luar — supaya tiap klaim bisa ditelusuri balik ke SQL yang menghasilkannya.

MESSE MySQL → RAW (Snowflake) → MART · signal + Kelly → Cortex Analyst → CoCo CLI agent

Karena MESSE tidak punya data transaksi broker IDX, layer MART dibangun dari skor akumulasi/distribusi milik MESSE sendiri (bukan broker net-flow) — lihat "Known gaps" di README repo untuk detail lengkap keputusan ini dan batas-batasnya.
